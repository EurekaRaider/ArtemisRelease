# Artemis

Artemis 是面向编程、研究和日常工作的 AI 桌面工作空间，让对话、文件与任务集中在一起。

本仓库用于发布 Artemis 安装包和版本更新。前往 [Releases](https://github.com/EurekaRaider/ArtemisRelease/releases) 查看可用版本。

## 功能亮点

- **编程与项目协作**：理解项目、修改代码、审阅变更，持续推进开发任务。
- **文档与日常办公**：处理文档、PDF、表格和演示文稿，整理资料与研究结果。
- **持续任务与项目记忆**：保留任务上下文，随时继续之前的工作。
- **多智能体协作**：让不同角色分工处理任务，在同一工作空间查看进展与结果。
- **聊天工具接入**：通过常用通讯工具发送任务，在群聊中开展协作。
- **按需扩展与自动化**：选择适合的模型、添加技能和插件，为重复工作设置定时任务。
